How AccuKnox Asset Check Works

Discover, inventory, and understand your cloud resources across AWS, Azure, GCP, and Oracle — in minutes.

Step 1 🔑
Configure Credentials
Use your existing CLI credentials — AWS CLI, Azure CLI, gcloud, or OCI config. No new accounts needed.
→
Step 2 ☁️
Select Clouds
Configured providers are auto-detected and highlighted. Pick one or many to scan.
→
Step 3 🔍
Run Scan
Choose Billable (fast, ~30s) or Full inventory. The tool queries every region in parallel.
→
Step 4 📊
Explore Results
Charts, filters, and a sortable table show every asset. Export to CSV or HTML report.
Supported Cloud Providers
🟠
Amazon AWS
Uses AWS CLI / IAM credentials (~/.aws/credentials)
🔵
Microsoft Azure
Uses Azure CLI / DefaultAzureCredential (az login)
🔷
Google Cloud
Uses Application Default Credentials (gcloud auth)
🔴
Oracle OCI
Uses OCI config file (~/.oci/config)
Key Features
💰
Billability Detection
Resources are marked billable or non-billable based on configurable lists (e.g. aws-billable-assets.txt). Edit these files to match your pricing model.
⚡
Two Scan Modes
Billable — scans only cost-incurring resource types (~30 seconds). Full — scans every supported service type across all regions.
📋
Filter & Search
Filter by cloud, category, type, region, or billability. Full-text search across name and ID. Sort any column.
📥
Export Reports
Download a CSV for spreadsheet analysis or a styled HTML report to share with your team — no login required to view.
🔄
Scan Persistence
Refresh the page without losing results. Running scans automatically resume polling; completed results are restored from the server.
🎨
Dark & Light Mode
Toggle between themes using the ☀️/🌙 button. Your preference is saved across sessions.
Read-Only Credentials (Recommended)

This tool only reads from your cloud accounts. For best security, restrict its credentials to read-only access:

🟠
AWS
aws iam attach-user-policy --user-name YOUR_USER --policy-arn arn:aws:iam::aws:policy/ReadOnlyAccess
🔵
Azure
az role assignment create --role Reader --assignee YOUR_PRINCIPAL --scope /subscriptions/SUB_ID
🔷
GCP
gcloud projects add-iam-policy-binding PROJECT_ID --member="serviceAccount:SA" --role="roles/viewer"
For user credentials: gcloud auth application-default login (scopes enforced automatically)
🔴
Oracle OCI
Use only inspect and read verbs in OCI policies:
Allow group ReadOnlyGroup to inspect all-resources in tenancy
Allow group ReadOnlyGroup to read all-resources in tenancy
